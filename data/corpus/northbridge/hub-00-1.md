# Data lineage: a practical introduction

The following notes summarise a talk given at a member networking evening. Lineage diagrams go out of date quickly unless updating them is part of the change process.

Data lineage records where a data set came from and every step that changed it on the way. Automated lineage tools read SQL and pipeline code, but they rarely capture spreadsheets or manual steps.

When a figure in a report looks wrong, lineage lets an analyst trace it back to the source system. Start with the reports that executives rely on most and document their lineage first.
