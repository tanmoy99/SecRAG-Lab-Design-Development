# Spreadsheet risk: a checklist for small teams

Members often ask us where to start with this topic, so we have collected some practical advice. A simple review checklist catches most spreadsheet errors before a report is published.

Version control is rarely used for spreadsheets, which makes it hard to know which copy is current. Hidden rows, hard-coded numbers and broken links cause many of the errors found in spreadsheet audits.

When a spreadsheet becomes business-critical, it is time to consider moving the logic into code or a database. Spreadsheets remain the most widely used analytics tool in small organisations.
