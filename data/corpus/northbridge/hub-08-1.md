# Ethical review of analytics: questions to ask before you start

The following notes summarise a talk given at a member networking evening. Documenting the reasons for a decision protects both the organisation and the people affected.

Not every analytics project needs a formal ethics review, but every project should ask who could be harmed. An ethics checklist is a starting point for discussion, not a box-ticking exercise.

Linking data sets can reveal far more about people than either data set does alone. Community expectations are a useful test: would the people in the data be surprised by this use?
