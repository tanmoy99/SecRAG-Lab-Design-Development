# Cloud cost control: a practical introduction

This short piece draws on discussions at recent member events. Storage is cheap, but scanning large tables repeatedly in queries is not.

Tagging resources by team or project is the first step towards understanding cloud spend. Idle compute clusters and forgotten test environments are common sources of waste.

Budgets and alerts should be set up before a platform is opened to many users. Cloud data platforms make it easy to start small, but costs can grow quickly without guardrails.

Members who want to go further may be interested in Cloud Data Platforms, listed in the Institute's course catalogue.
