# Cloud cost control: a checklist for small teams

Members often ask us where to start with this topic, so we have collected some practical advice. Tagging resources by team or project is the first step towards understanding cloud spend.

Idle compute clusters and forgotten test environments are common sources of waste. Storage is cheap, but scanning large tables repeatedly in queries is not.

Cloud data platforms make it easy to start small, but costs can grow quickly without guardrails. Budgets and alerts should be set up before a platform is opened to many users.

Members who want to go further may be interested in Cloud Data Platforms, listed in the Institute's course catalogue.
