# Spreadsheet risk: lessons from the field

The following notes summarise a talk given at a member networking evening. When a spreadsheet becomes business-critical, it is time to consider moving the logic into code or a database.

Spreadsheets remain the most widely used analytics tool in small organisations. A simple review checklist catches most spreadsheet errors before a report is published.

Version control is rarely used for spreadsheets, which makes it hard to know which copy is current. Hidden rows, hard-coded numbers and broken links cause many of the errors found in spreadsheet audits.
