# Cloud cost control: questions to ask before you start

This article is part of the knowledge hub series for members working in small and medium organisations. Storage is cheap, but scanning large tables repeatedly in queries is not.

Cloud data platforms make it easy to start small, but costs can grow quickly without guardrails. Idle compute clusters and forgotten test environments are common sources of waste.

Tagging resources by team or project is the first step towards understanding cloud spend. Budgets and alerts should be set up before a platform is opened to many users.

This topic is covered in more depth in CL250 Cloud Data Platforms.
