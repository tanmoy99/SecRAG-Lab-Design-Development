# Cloud cost control: common mistakes to avoid

Members often ask us where to start with this topic, so we have collected some practical advice. Idle compute clusters and forgotten test environments are common sources of waste.

Storage is cheap, but scanning large tables repeatedly in queries is not. Budgets and alerts should be set up before a platform is opened to many users.

Tagging resources by team or project is the first step towards understanding cloud spend. Cloud data platforms make it easy to start small, but costs can grow quickly without guardrails.

Members who want to go further may be interested in Cloud Data Platforms, listed in the Institute's course catalogue.
