# Dashboard design: common mistakes to avoid

The following notes summarise a talk given at a member networking evening. Ask users what decisions the dashboard supports before choosing any charts.

Every dashboard should say where its data comes from and when it was last refreshed. A good dashboard answers a small number of questions for a specific audience.

Too many charts on one screen make it harder, not easier, to see what matters. Consistent colours and clear labels matter more than visual effects.
