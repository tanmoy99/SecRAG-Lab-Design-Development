# Data lineage: common mistakes to avoid

This short piece draws on discussions at recent member events. When a figure in a report looks wrong, lineage lets an analyst trace it back to the source system.

Automated lineage tools read SQL and pipeline code, but they rarely capture spreadsheets or manual steps. Data lineage records where a data set came from and every step that changed it on the way.

Lineage diagrams go out of date quickly unless updating them is part of the change process. Start with the reports that executives rely on most and document their lineage first.
