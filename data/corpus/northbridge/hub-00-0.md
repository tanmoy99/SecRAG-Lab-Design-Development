# Data lineage: what we learned this year

Members often ask us where to start with this topic, so we have collected some practical advice. Start with the reports that executives rely on most and document their lineage first.

Automated lineage tools read SQL and pipeline code, but they rarely capture spreadsheets or manual steps. Data lineage records where a data set came from and every step that changed it on the way.

When a figure in a report looks wrong, lineage lets an analyst trace it back to the source system. Lineage diagrams go out of date quickly unless updating them is part of the change process.

Members who want to go further may be interested in Metadata and Data Catalogues, listed in the Institute's course catalogue.
